Car Price Dataset – Data Cleaning and Preprocessing
About the Project

This project focuses on cleaning and preprocessing a car price dataset using Python and Pandas.

Data Cleaning and Preprocessing

The following tasks were performed:

Checked the dataset structure and data types
Checked for missing values
Checked for duplicate records
Cleaned and converted data types
Extracted and formatted year information
Cleaned car name and related columns
Encoded categorical columns where required
Checked outliers
Prepared the dataset for further analysis
